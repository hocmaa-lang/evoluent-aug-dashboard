## How the team shares progress
Ticks and metric values are stored per browser. To share one master copy:

1. The owner clicks **Export progress** and copies the text.
2. Edit `state.json` in this repo and paste it as the `state` value:
   `{"updated":"2026-08-19","by":"Name","state":{ ...pasted... }}`
3. Everyone else clicks **Load team master** to pull it in.
